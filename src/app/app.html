WEB APPLICATION

Urgences Médicales

@if (isFrench()) {

Urgences Médicales est une application web de gestion d'un service d'urgences hospitalier. Elle organise le triage des patients avec une file d'attente prioritaire, le suivi des lits et des équipements, et une banque de sang complète (stock, donneurs, demandes). Les accès dépendent du rôle (médecin, infirmier, accueil), chaque action est tracée dans un journal d'activité et un tableau de bord présente les indicateurs clés. Développée en PHP (architecture MVC) et MySQL, avec requêtes préparées, protection CSRF et mots de passe hachés.

} @if (isEnglish()) {

Urgences Médicales is a web application for managing a hospital emergency department. It handles patient triage with a priority waiting queue, tracking of beds and equipment, and a complete blood bank (stock, donors, requests). Access depends on the user role (physician, nurse, front desk), every action is recorded in an activity log, and a dashboard presents the key indicators. Built with PHP (MVC architecture) and MySQL, using prepared statements, CSRF protection and hashed passwords.

}
